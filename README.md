# Task Management System — Frontend

A React SPA built with **Vite** and **TypeScript**, featuring TanStack Router for type-safe routing, TanStack Query for server state, shadcn/ui components, and Tailwind CSS v4.

> Backend: [task-management-system-nest](https://github.com/starcrafter1345/task-management-system-nest)

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19, TypeScript |
| Build tool | Vite 7 |
| Routing | TanStack Router v1 |
| Server state | TanStack Query v5 |
| Forms | React Hook Form, Zod |
| HTTP client | Axios |
| UI components | shadcn/ui, Radix UI |
| Styling | Tailwind CSS v4 |
| Icons | Lucide React |
| Dark mode | next-themes |
| Notifications | Sonner |
| Utilities | date-fns, js-cookie, react-colorful |
| Package manager | pnpm |

---

## Prerequisites

- [Node.js](https://nodejs.org/) v18+
- [pnpm](https://pnpm.io/)
- Backend running at `http://localhost:3000` — see [task-management-system-nest](https://github.com/starcrafter1345/task-management-system-nest)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/starcrafter1345/task-management-system-frontend.git
cd task-management-system-frontend
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Set up environment variables

Create a `.env` file in the root directory:

```env
VITE_API_URL=http://localhost:3000
```

### 4. Start the development server

```bash
pnpm run dev
```

The app will be available at `http://localhost:5173`.

## Project Structure

```
src/
├── routes/           # TanStack Router file-based route definitions
│   ├── __root.tsx    # Root layout
│   ├── index.tsx     # Home / dashboard
│   ├── login.tsx     # Login page
│   └── ...
├── components/       # Reusable UI components (shadcn/ui + custom)
├── api/              # Axios instance and request helpers
├── hooks/            # Custom React hooks
├── types/            # TypeScript interfaces and types
├── lib/              # Utility functions (cn, etc.)
├── assets/           # Static assets
├── main.tsx          # App entry point
└── routeTree.gen.ts  # Auto-generated by TanStack Router (do not edit)
```

> `routeTree.gen.ts` is generated automatically by the `@tanstack/router-plugin` Vite plugin on every dev/build run. Do not edit it manually.

## Adding shadcn/ui Components

This project uses [shadcn/ui](https://ui.shadcn.com/). To add a new component:

```bash
pnpx shadcn@latest add <component-name>
```
